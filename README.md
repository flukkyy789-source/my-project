# Student Task Manager 📚

เว็บแอปจัดการงานสำหรับนักศึกษา พัฒนาด้วย HTML, CSS และ JavaScript

## ฟังก์ชัน
- เพิ่มงานและกำหนดวันส่ง
- ทำเครื่องหมายงานที่เสร็จแล้ว
- ลบงาน
- ค้นหางาน
- กรองงานตามสถานะ
- บันทึกข้อมูลด้วย LocalStorage

## วิธีใช้งาน
เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์

## โครงสร้างโปรเจกต์
```text
student-task-manager/
├── index.html
├── style.css
├── script.js
└── README.md
```
